# Code Typer Multiplayer

## Description
A multiplayer variant of Code Typer where players compete simultaneously in real-time to type out exactly the same block of code as accurately and quickly as possible. The game displays players' progress and rankings dynamically as they race to finish the code snippet.

## Scoring
- Words per minute (WPM)
- Number of errors
- Overall accuracy percentage

**Winner**: The winner is determined by the player who finishes the code block first with the highest overall accuracy.
