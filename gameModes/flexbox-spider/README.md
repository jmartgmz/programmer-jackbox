# Flexbox Spider

## Description
A web development puzzle gamemode focused on mastering CSS Layouts. Inspired by hits like Flexbox Froggy, players must use CSS flexbox properties to guide a spider into a web or specific target zones on the board.

## Mechanics
Players type CSS flexbox rules into an integrated CSS editor. The game challenges players with increasingly difficult layouts. They use properties such as `justify-content`, `align-items`, `flex-direction`, and more to strategically position their spider. 

The first player to accurately complete the layout challenge with the minimum amount of CSS rules wins the round.
