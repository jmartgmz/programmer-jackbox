# Escape the Loop

## Description

A logic puzzle and debugging gamemode where players are given a faulty piece of code stuck in an infinite loop. The objective is to analyze the logic, find the error, and write the correct exit condition or patch to "escape the loop".

## Settings

The host can set the specific programming language, the difficulty of the infinite loops, and the time limit for solving each puzzle. Players earn points based on how quickly they correctly escape the loop.
